# shimmer

High sparkle, ~1.2s: a cluster of high sine partials with slow shimmering amplitude. Magic,
bright reveals, "elegant" accents.

Moods: calm, playful, upbeat

## When to use
- bright / magical reveals                   →  when: "beat:reveal"
- premium brand moments, elegant transitions
- "shine" accents on glowing elements

## When NOT to use
- in serious/tense scenes (shimmer reads "magic", not "gravity")
- when `sparkle` (random twinkles) is the better celebration tool

## Parameters
None — fixed character (use `volume` to control glow).

## Examples
{ "sound": "shimmer", "when": "beat:reveal", "volume": 0.3 }
