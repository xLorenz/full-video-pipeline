# bubble

Water bubbles (CC0 sample, ~0.7s). Soft bubbling — underwater scenes, droplets template,
liquid accents.

Moods: calm, playful

## When to use
- underwater moments                     →  when: "beat:bubble"
- droplets template / rain-on-glass scenes
- liquid metaphors ("the market is underwater")

## When NOT to use
- in serious/tense scenes (bubbles read light and playful)
- without a liquid visual reference

## Parameters
None (sample playback; use `volume` to control pop).

## Examples
{ "sound": "bubble", "when": "beat:bubble", "volume": 0.35 }
