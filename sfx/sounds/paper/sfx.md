# paper

Paper rustle / page flip (CC0 sample, ~0.8s). Dry, organic rustle — documents, letters,
dossiers, page turns.

Moods: calm, neutral

## When to use
- documents / letters / files appear          →  when: "beat:paper"
- page flips in listicles or multi-part content
- historical / archival scenes

## When NOT to use
- for digital UI — `click` is the neutral digital sound
- in tense action scenes (paper implies stillness)

## Parameters
None (sample playback; use `volume` to control rustle).

## Examples
{ "sound": "paper", "when": "beat:letter", "volume": 0.4 }
