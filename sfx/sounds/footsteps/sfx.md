# footsteps

Three footsteps, ~0.85s (CC0 sample: three steps concatenated at ingest). Approach, walking,
tension-building footsteps.

Moods: tense, serious

## When to use
- someone approaches                      →  when: "beat:approach"
- walking / running scenes
- countdown-style "they're coming" beats

## When NOT to use
- in calm scenes — footsteps signal movement and usually threat
- without a visual walking/approach reference

## Parameters
None (sample playback; use `volume` to control distance — lower volume = more distant).

## Examples
{ "sound": "footsteps", "when": "beat:approach", "volume": 0.35 }
