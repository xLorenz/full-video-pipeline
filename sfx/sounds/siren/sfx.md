# siren

Distant siren (CC0 sample, ~3.5s). A distant emergency siren — warning beats, security,
"danger approaching".

Moods: serious, tense

## When to use
- warning beats ("the system is compromised")
- security / surveillance scenes
- establishing dread before a reveal

## When NOT to use
- **in playful content — a siren there is a tone error; validation will warn.**
- at high volume under narration — keep it distant (volume ≤ 0.35)
- more than once per video (sirens mark emergency, not ambience)

## Parameters
None (sample playback; use `volume` to control distance).

## Examples
{ "sound": "siren", "when": "beat:warning", "volume": 0.25 }
