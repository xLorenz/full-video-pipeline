# door

Door closing thud (CC0 sample, ~0.7s). Wooden door close — reveals, entrances, chapter
boundaries.

Moods: tense, serious, calm

## When to use
- a door opens/closes on screen            →  when: "beat:door"
- entrances and exits ("he walks in")
- scene boundaries (a door closing ends a beat)

## When NOT to use
- without a door-related visual
- in scenes with no spatial reference (a door thud implies a room)

## Parameters
None (sample playback; use `volume` to control proximity).

## Examples
{ "sound": "door", "when": "beat:door_open", "volume": 0.35 }
