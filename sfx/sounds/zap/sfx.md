# zap

Electric snap, ~0.16s: a 3 ms crackle burst, a crackling arc sizzle (chopped band-passed
noise) and a small sub thump. Short, bright, unmistakably electric.

Moods: glitch, tense, playful, neutral

## When to use
- error hits, sci-fi pulses                     when: "beat:zap"
- electric/energy metaphors in infographics
- the moment a machine "powers" a UI element

## When NOT to use
- for slow or sad beats — it is a sharp, short accent
- as a riser (use `riser` for build-ups)

## Parameters
None — fixed character (use `volume` to control sting).

## Examples
{ "sound": "zap", "when": "beat:zap", "volume": 0.5 }
