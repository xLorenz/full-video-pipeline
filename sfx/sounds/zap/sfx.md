# zap

Electric snap, ~0.2s: a short square-wave burst with a fast high-frequency decay — an
electrical "crack". Errors, sci-fi pulses, glitch accents.

Moods: glitch, tense, playful, neutral

## When to use
- error / fail UI moments                    →  when: "beat:error"
- sci-fi / cyber content pulses
- electric accents (with `glitch_burst` for visual glitches)

## When NOT to use
- more than 2 zaps per scene (it is a sharp irritant by design)
- in calm scenes — `tick` or `click` cover neutral UI

## Parameters
None — the character is fixed (use `volume` to control sting).

## Examples
{ "sound": "zap", "when": "beat:error", "volume": 0.4 }
